# `Selection Sort`
## 1. `Selection Sort` là gì?
- tìm phần tử min trong phần chưa sắp xếp -> đưa nó lên đầu
``` c++
a[] = {7,3,9,2,5} // min = 2
// so từng phần tử
{3,7,9,2,5}
{2,3,7,9,5}
{2,3,5,7,9}
```

khác với `bubble sort` : so sánh kế tiếp -> swap
